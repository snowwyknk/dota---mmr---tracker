# Dota 2 MMR Tracker

Личный Steam-вход и калькулятор MMR. Пользовательские профили приватные: сервер не предоставляет публичный список профилей. Steam подтверждает аккаунт; имя и аватар загружаются из публичного профиля Steam через Steam Web API. Пароль Steam сайт не получает. MMR пользователь вводит и обновляет вручную.

## Структура

- `public/` — публичные HTML-страницы и статические файлы.
- `public/assets/css/` — стили.
- `public/assets/js/` — логика интерфейса и калькулятора.
- `public/assets/images/` — фон сайта, медали рангов и значки уровней Dota Plus.
- `public/assets/vendor/` — локальные стили Bootstrap без внешнего CDN.
- `server/` — Express-сервер, Steam OpenID, сессии и приватные API профиля.
- `migrations/` — SQL-схема PostgreSQL, включая Steam-данные и прогресс героев.
- `test/` — тесты Steam ID, профиля Steam, валидации MMR и опыта героев.

Калькулятор Dota Plus использует таблицу опыта уровней 1–30 в `public/assets/js/hero-progression.js` и доступен без входа. После входа через Steam можно сохранять приватные записи нескольких героев и открывать их в калькуляторе. Форма обратной связи открывает почтовое приложение с подготовленным письмом; сайт не принимает и не хранит текст отзывов.

## Локальный запуск

Требуется Node.js 18 или новее и доступ к PostgreSQL.

1. Скопируйте `.env.example` в `.env`.
2. Укажите PostgreSQL connection string в `DATABASE_URL`. Создайте случайный секрет командой `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` и сохраните его в `SESSION_SECRET`.
3. Выполните `npm ci`.
4. Запустите `npm start` и откройте `http://localhost:3000`.

Вход подтверждается Steam OpenID: сайт никогда не получает пароль Steam. Каждый вход имеет одноразовое состояние с ограниченным сроком действия; отменённый или некорректный ответ Steam безопасно возвращает пользователя на сайт. Схема профилей и таблица сессий создаются сервером автоматически. Чтобы получать публичное имя и аватар, задайте `STEAM_API_KEY` в `.env` или секретных переменных Render. Если ключ не задан или Steam Web API временно недоступен, вход продолжит работать, а профиль покажет запасное имя и значок. Steam API key не даёт доступ к паролю пользователя; импорт игровой статистики пока не включён.

## Публикация: Render + Neon

Для запуска без оплаты используйте планы Neon Free и Render Free, а вместо покупки домена — выданный Render адрес `*.onrender.com` с автоматическим HTTPS. Это вариант для теста и небольшого хобби-проекта: бесплатный Render-сервис засыпает после 15 минут без запросов и может запускаться около минуты; перед публикацией для широкой аудитории проверьте актуальные [ограничения Render Free](https://render.com/docs/free) и [условия Neon Free](https://neon.com/pricing). Проверка домена `d2traker.com` через DNS и RDAP сейчас не обнаруживает регистрацию; адрес `.com` обычно требует отдельной оплаты.

1. В Neon создайте проект `dota-mmr-tracker` в регионе Frankfurt, оставив включённым только PostgreSQL. В **Connect** выберите **Direct connection**: сервер работает постоянно и запускает миграции при старте. Скопируйте строку подключения с SSL (`sslmode=require`).
2. Загрузите проект в свой GitHub-репозиторий. Не добавляйте `.env`, строку Neon или `node_modules`.
3. В Render создайте Blueprint из репозитория и примените `render.yaml`. Для `DATABASE_URL` вставьте строку Neon в защищённое поле переменных окружения. Blueprint сам сгенерирует `SESSION_SECRET`.
4. Запустите сервис. При первом запуске сервер проверит подключение и создаст таблицы профилей, одноразовых Steam nonce и сессий.
5. Render автоматически выдаст адресу сервиса HTTPS-сертификат. Приложение использует предоставленный Render адрес, поэтому `BASE_URL` для стандартного адреса `*.onrender.com` задавать не нужно.
6. Чтобы показывать Steam-ник и аватар, получите Web API key на [странице Steam API Key](https://steamcommunity.com/dev/apikey), указав публичный адрес Render как домен. В Render откройте сервис → **Environment** → **Add Environment Variable** и задайте `STEAM_API_KEY` со значением ключа. Не добавляйте ключ в GitHub. После сохранения Render перезапустит сервис; затем выйдите из профиля на сайте и войдите через Steam ещё раз, чтобы обновить имя и аватар.
7. Проверьте `https://<адрес-сервиса>/health`, затем выполните тестовый вход через Steam и убедитесь, что профиль загружается после возврата на сайт.

Для собственного домена сначала добавьте его в настройках Render и настройте DNS по выданным Render записям. Для выбранного домена `d2traker.com` после его регистрации укажите в Render `BASE_URL=https://d2traker.com` (без пути и завершающего слеша). Перезапустите сервис после выпуска HTTPS-сертификата: Steam OpenID использует этот адрес для возврата после входа.

На бесплатном тарифе Render сайт может засыпать после простоя и медленнее открываться при первом посещении.

Секреты храните только в локальном `.env` и настройках хостинга. Не публикуйте их в репозитории и не отправляйте в чаты.
